# វគ្គ Python ពីមូលដ្ឋានដល់កម្រិតខ្ពស់

វគ្គនេះបង្រៀន Python ជាភាសាខ្មែរ តាមលំដាប់ពីការដំឡើង រហូតដល់ការរចនា ការសាកល្បង និងការដាក់កម្មវិធីឱ្យដំណើរការ។ មេរៀននីមួយៗមានគោលដៅ ពន្យល់ជំហានៗ កូដអាចរត់បាន កំហុសដែលជួបញឹកញាប់ និងលំហាត់។

## មុនចាប់ផ្តើម

- កុំព្យូទ័រដែលអាចដំឡើង Python និង editor ដូចជា VS Code។
- ឧទាហរណ៍ក្នុងវគ្គប្រើ syntax ដែលដំណើរការលើ Python 3.12 ឡើង។ បច្ចុប្បន្នអាចរៀនជាមួយ Python 3.15; ពេលបង្កើត project ពិត សូមពិនិត្យ version និង compatibility របស់ dependency។
- រត់ឧទាហរណ៍ក្នុង terminal។ ពេលដល់មេរៀន environment សូមបង្កើត virtual environment ដាច់ដោយឡែកសម្រាប់ project។
