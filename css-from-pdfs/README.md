## ប្រធានបទពីឯកសារដើមដែលបានរៀបចំ

- ឯកសារ CSS, inline/internal/external stylesheets និង selectors។
- Element, ID និង class selector។
- Text/font: color, family, size, weight, style, alignment, decoration, transform, spacing និង line-height។
- Box model: margin, padding, width/height, min/max width និង box-sizing។
- Border, outline, background, shadow, opacity, filter និង cursor។
- Positioning, display, visibility, overflow និង stacking order។
- Flexbox, Grid និង gap។
- Form fields និង navigation menu ផ្ដេក/បញ្ឈរ។
- Transition និង keyframe animation។

## របៀបអនុវត្ត

1. បង្កើត folder មួយសម្រាប់មេរៀននីមួយៗ ឬប្រើ project ដូចគ្នាតាមលំដាប់។
2. សរសេរ HTML មុន ដើម្បីបង្កើតរចនាសម្ព័ន្ធ និងអត្ថន័យ។
3. ភ្ជាប់ឯកសារ CSS ដាច់ដោយឡែក ហើយសរសេរ rule មួយម្តង។
4. បើក browser DevTools ដើម្បីពិនិត្យ selector, computed styles និង box model។
5. សាក viewport តូច, keyboard focus និងអត្ថបទខ្មែរ មុនចាត់ថាការងាររួច។
