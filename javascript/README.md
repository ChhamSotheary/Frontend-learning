# វគ្គសិក្សា JavaScript ពីមូលដ្ឋានដល់កម្រិតខ្ពស់

វគ្គនេះបង្រៀន JavaScript ជាភាសាខ្មែរ តាមលំដាប់ពីការសរសេរកូដដំបូង រហូតដល់ browser programming, asynchronous code, Node.js, testing, security និង architecture។ មេរៀនមួយៗមានគោលបំណង, ការពន្យល់ជាជំហាន, ឧទាហរណ៍កូដ, កំហុសទូទៅ, លំហាត់ និងចម្លើយសម្រាប់ផ្ទៀងផ្ទាត់។

## របៀបរៀន

1. រៀនតាមលំដាប់លេខមេរៀន ព្រោះមេរៀនក្រោយប្រើគំនិតពីមេរៀនមុន។
2. វាយកូដដោយខ្លួនឯង ហើយព្យាករណ៍ output មុន run។
3. រត់ឧទាហរណ៍ `.js` ដោយ Node.js ឬសាក browser snippets ក្នុង Developer Tools Console។
4. បែងចែកឱ្យច្បាស់រវាង JavaScript language, browser APIs និង Node.js APIs។
5. មុនប្រើ feature ថ្មី ពិនិត្យថា browser/Node.js version គោលដៅគាំទ្រឬអត់។
6. React និង framework ផ្សេងៗរៀនក្រោយពេលយល់ JavaScript មូលដ្ឋាន និង DOM។

## តម្រូវការមុនចាប់ផ្តើម

- មិនចាំបាច់មានបទពិសោធន៍ JavaScript ទេ។
- គួរស្គាល់ HTML មូលដ្ឋាន ដូចជា element, attribute, link និង form ពេលចាប់ផ្តើមផ្នែក browser។
- ត្រូវមាន browser ទំនើប និង Node.js ដើម្បី run ឧទាហរណ៍ក្នុង terminal។ ទាញយក Node.js ពីគេហទំព័រផ្លូវការ។
